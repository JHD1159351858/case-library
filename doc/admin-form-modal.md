# 管理端新增智能体弹窗

2026-10-12：将新增 / 编辑共用表单从列表下方移入弹窗。「现有智能体记录」右侧新增「新增智能体」按钮；点击后恢复当前账号的本地新增草稿，无草稿时打开空表单，点击记录的「编辑」则回填原有字段。

沿用原有配色、表单校验、图片上传及接口。点击弹窗外的遮罩不关闭表单，关闭按钮和 Esc 可主动关闭。新增表单关闭时自动暂存，编辑模式关闭时取消编辑，迟到的上传 / 编辑响应不会回填。保存期间禁止关闭，成功后关闭并刷新数据，失败时保留填写内容与错误提示。手机显示可滚动的底部弹窗。

新增表单底部提供「暂存草稿」按钮。草稿按管理员账号保存在当前浏览器的 localStorage 中，不创建正式案例、不上传草稿到服务器，其他浏览器无法恢复。暂存不要求名称必填或扩展 JSON 已完成，原始文字和已上传封面地址均保留。暂存后刷新页面、重新打开表单可恢复；新增成功或点击「清空表单」后清除草稿。编辑现有案例不会覆盖新增草稿。浏览器存储失败时提示错误并保留当前输入。
