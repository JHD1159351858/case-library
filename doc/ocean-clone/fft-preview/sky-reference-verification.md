# 参考天空接入记录

日期：2026-10-22。预览：http://127.0.0.1:1002/ocean/real/

## 变更

按用户最新要求，将原有去字海面素材通过内置 imagegen 编辑为纯天空图片 `project/frontend/ocean/assets/sky-reference.png`。实际尺寸 2172×724，已目视确认无文字、海水或界面元素。完整提示词保存在同目录 `sky-reference.md`。

天空与海浪环境反射使用相同世界方向投影。照片在加载时一次性逆色调映射到 HDR，再进入现有统一后处理，避免二次色调映射造成的灰白色。照片角度范围外平滑接入原有程序天空。太阳仰角根据新素材调整至 5°。FFT 海浪、相机下潜和水下体积散射算法保持原有实现。

## 验证

- 四个涉及渲染的 JavaScript 模块通过 `node --check`。
- 浏览器确认天空 PNG 请求返回 HTTP 200。
- 首次运行发现 WGSL 保留关键字 `target`；已更名为 `desired`，刷新后渲染器为 `webgpu-fft`，加载提示隐藏，未新增着色器错误。
- 已目视检查天空、动态海浪及其反射；下潜至进度 1.000、相机 -7 m 时，画面进入原有水下场景，未留下整张天空覆盖层；返回海面正常。
- 当前窗口 GPU 单帧时间采样约 5.18–6.79 ms，仅为本机采样，不是全面性能基准。
- 证据：`sky-reference-surface.png`、`sky-reference-underwater.png`。

天空是静态素材，海浪、倒影与水下光束实时运动。窄窗口会依视角裁掉图片两侧，太阳可能在画面外；未改变原有镜头视野。素材不是完整 360° HDR 环境，超出范围仍由程序天空补足。未进行手机实机性能验证。
