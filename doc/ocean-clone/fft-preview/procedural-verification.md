# 纯代码海洋验证记录

日期：2026-10-22

此记录为纯代码版本的历史验证。后续按用户要求改为纯天空图片加代码海浪，当前状态见 `sky-reference-verification.md`。

预览：http://127.0.0.1:1002/ocean/real/

## 本轮实现

- 移除该路线的照片加载、背景照片纹理及照片颜色混合分支；天空、云层、海浪、水下颜色和光束均由代码生成。
- 保留六级 FFT 海浪，使镜头随滚动下降并穿过同一片动态水面；调整入水前的仰角和随浪运动。
- 根据镜头近裁剪面与当地水面的位置连续混合水上、水下材质；统一近景海浪网格精度，减少近距离棱角。
- 水下体积采样改为固定距离步长，消除此前随射线距离变化的弧形亮度边界。
- 旧 `/ocean/` 图片版本保持原有入口。

## 检查结果

- 本地 HTTP 返回 200，WebGPU 场景实际渲染成功。
- 浏览器请求记录包括 HTML、CSS、JavaScript、字体和 SVG 图标；没有背景图片或视频请求。
- 当前标签页没有控制台警告或错误；WGSL 管线在浏览器中编译、运行成功。
- 四个修改的 JavaScript 文件通过 `node --check`。
- 实际检查了向下滚动、反向滚动、返回海面以及暂停/继续播放。
- 两张同一水下视角、不同时间的截图尺寸均为 688×919，90.10% 的像素至少一个 RGB 通道变化超过 8，支持水下场景持续运动的判断；这不是动画质量或流畅度评分。
- 最终返回海面时滚动进度为 0，播放按钮显示 Pause ocean animation；页面保持运行供继续预览。
- 本机当前视口的 GPU 单帧时间采样约 5.95–6.47 ms，仅为观察时刻的采样，不代表完整帧率测试或移动设备性能。

## 已知差距

程序化云层形态、波浪细节及水下散射仍与参考照片存在明显风格和摄影质感差距，尚未做到完全一致。入水处采用近裁剪面浸没近似，极近距离看浪面的观感仍有简化；没有模拟翻卷碎浪、完整水花或真实流体。当前是开放水体，没有加入参考图之外的海床。低端设备和手机实机性能尚未验证，运行需要 WebGPU 支持。
